IPYDEMO.polyhedra — Polyhedra exploration

This module provides tools to display and explore polyhedra.

Available types and functions

IPYDEMO.polyhedra.core.draw(G, E_COLOURS=None, N_COLOURS=None, TITLE='{name}', **ka)[source]

Draws multiple views of a graph. The views differ only by the colouring of nodes and edges. Assumptions:

  • G has a graph attribute views, which is a dict mapping each view name to a title

  • Each node of G has a node attribute position as an array (in 2D)

  • Each node and each edge of G may have a node or edge attribute colour, which is a dict mapping each of a set of view names to a colour index

  • G may have graph attribute e_colours (resp. n_colours), which is a dict mapping edge (resp. node) colour indices to matplotlib colour names

Parameters:

  • G (Graph) – the graph to draw

  • E_COLOURS (Mapping[int, str] | None) – dict mapping edge colour indices to matplotlib colour names, overriding the items in attribute e_colours of G

  • N_COLOURS (Mapping[int, str] | None) – dict mapping node colour indices to matplotlib colour names, overriding the items in attribute n_colours of G

  • TITLE (str) – string format for the title of the overall figure (the format variables are the graph attribute names)

IPYDEMO.polyhedra.core.colouring(N, R, *init)[source]

Enumerates minimal solutions to a colouring problem on a set of nodes and a set of clusters (of nodes). A solution is a pair of an assignment of a colour to each node so that any two nodes in the same cluster have different colours. A minimal solution is a solution using a minimal number of colours.

A solution is given as a mapping of each node to a colour. To respect the constraint with \(C\) colours, we must have

\[\begin{equation*} \max_{r\in R}|r| \;\;\leq\;\; C \;\;\leq\;\; |N| \end{equation*}\]

This is solved by MILP.

  • Variables: one binary mip-variable \(x_{nc}\) for each node \(n\) and colour \(c\), specifying whether node \(n\) has colour \(c\).

  • Each node \(n\) has exactly one colour: \(\sum_cx_{nc}=1\)

  • For each cluster \(r\) and each colour \(c\), at most one node in \(r\) has colour \(c\): \(\sum_{n\in r}x_{nc}\leq1\)

Parameters:

  • N (Sequence[int]) – the set of nodes

  • R (Sequence[Sequence[int]]) – the set of clusters

  • init (Sequence[Tuple[int, int]]) – an initialisation of some nodes as a list of node-colour pairs

Returns:

a pair of the total number of colours used and a solution

Return type:

Generator[Tuple[int, Mapping[int, int]]]

IPYDEMO.polyhedra.core.min_path_cover(G)[source]

Computes the minimum number of edge-disjoint paths needed to cover all the edges of an undirected graph.

A solution is a Multipath object.

This is solved by MILP. If \(v\) is a vertice and \(e\) an edge, let \(\gamma(v,e)=1\) if \(e\) is adjacent to \(v\) and \(0\) otherwise.

  • Variables:

    • one integer variable \(x_e\) for each edge \(e\), specifying its orientation in the multi-path: \(+1\) if it is the edge’s orientation and \(-1\) otherwise

    • one integer variable \(x_v\) for each vertex \(v\), representing an upper bound of the degree flow (absolute value of out-degree minus in-degree in the multi-path)

  • By definition, any vertex \(v\) satisfies \(|\sum_e\gamma(v,e)x_e|\leq x_v\)

  • The objective is to minimize \(\sum_vx_v\), which is twice the number of paths in the multi-path

Parameters:

G (networkx.Graph) – an undirected graph

Returns:

a pair of the number of covering paths, and a random solution

Return type:

Generator[Multipath]

class IPYDEMO.polyhedra.util.Polyhedron(name, K, labels, edges, connect_centre_to=None, **ka)[source]

Bases: Graph

Instances of this class are polyhedron graphs built from a specification which applies for each \(k{\in}0{:}K{-}1\) as follows:

  • A label \(a\) with coefficient \(z\) creates a node \((a,k)\) at \(z\exp{i\frac{2\pi k}{K}}\)

  • An instruction \((a,b,n)\) creates an edge from node \((a,k)\) to node \((b,(k{+}n)\textrm{ mod }K)\)

Parameters:

  • name (str) – name of the polyhedron

  • K (int) – rotational invariance of angle \(\frac{2\pi}{K}\)

  • labels (Mapping[str, float | complex]) – dictionary of labels with their coefficients

  • edges (Iterable[Tuple[str, str, int]]) – instructions to create edges

  • connect_centre_to (Optional[str]) – instruction to create edge to centre
