Bases: object

An instance of this class extracts credentials recognised by Apache from the CGI context.

class XPOSE.access.Accessor(directives, credentials=None)[source]

Bases: object

An instance of this class manages access to the xpose instances. This implementation is based on the apache authorisation framework.

Parameters:

  • directives (dict[str, str]) – mapping each access level to an access control directive (must be acceptable in .htaccess files)

  • credentials (Credentials | None) – the credential object against which the directives are checked
