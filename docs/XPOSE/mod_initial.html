XPOSE.initial — initialisation

To initialise an Xpose instance, run the command:

PYTHONPATH=<path-to-xpose-package> <python-exe> -m xpose.initial <arguments>

where

  • the PYTHONPATH enviroment variable must give access to the XPOSE package

  • the resulting cgi-script will use the same python executable as specified in the command

  • the meaning of the arguments can be obtained by passing option -h or --help

The command above assumes the name of the XPOSE package is xpose (default). It may be changed, in which case it must be changed in the -m option above, and must also be explicitly provided with option -x.

XPOSE.initial.run(_path, _cgi_script, _cgi_url, _config='./config.py', _load=None, _pname='xpose')[source]

Xpose instance initialisation.

Parameters:

  • _path (str) – a path to an existing directory where an Xpose instance is to be initialised, normally empty (except for re-initialisation)

  • _cgi_script (str) – a path where the cgi script for the management of the instance will be created

  • _cgi_url (str) – a url invoking _cgi_script

  • _config (str) – a path to an existing python file containing the configuration of the instance

  • _load (str) – a url from which to retrieve an initial dump of entries, loaded into the instance (if not None)

  • _pname (str) – the name of the XPOSE package
