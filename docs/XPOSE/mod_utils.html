class XPOSE.utils.CGIMixin[source]

Bases: object

A simple helper mixin that simplifies writing CGI resource classes. A resource class needs only define methods do_get(), do_put() etc. with no input argument and output as a pair of a content string and a header dictionary.

process_cgi()[source]

Selects and executes the do_* method of this resource. Catches all exceptions and return them as plain text with the appropriate HTTP status code (500 by default) and traceback as body.

static parse_input(mime='application/json', chunk=None)[source]

Parses input stream according to mime:

  • application/json: applies json parser

  • application/x-www-form-urlencoded: returns a dictionary (unsophisticated: no multiple values per key)

  • application/octet-stream: returns an iterator of byte strings

Parameters:

  • mime (str) – the mimetype to interpret the input

  • chunk (int) – never reads more than this amount of bytes (if not None)

class XPOSE.utils.IntStrConverter(symbols=None, perm=4, shift=None)[source]

Bases: object

An instance of this class is a bijection between the interval of whole numbers \(\{0\cdots2^D{-}1\}\) and the set of strings of length \(K=\frac{D}{P}\) of characters in symbols, which must be a string of length \(2^P\) with no repetition. Example with all default parameters (where \(D=20,P=5,K=4\)):

c = IntStrConverter() # all default parameters
assert all(c.str2int(c.int2str(n))==n for n in range(c.bound+1))
Parameters:

  • symbols (dict[str, str]) – a string with no repetition, clipped to have a size of the form \(2^P\) (default: random string of size \(32\))

  • perm (tuple[int, ...]) – a permutation of (\(0,\cdots,D-1\)) or the integer \(K\) (permutation randomly generated with \(D=KP\))

  • shift (int) – a non negative integer (default: random)

class XPOSE.utils.Backup(p, name='.backup')[source]

Bases: object

An instance of this class creates a context allowing transactional operations on the first level of a directory (called the root). A subdirectory of the root must be named, and will be used for backup. It should only be used for that purpose. The only allowed transactional operations take a single name (with no path separator) as input and move the file (or sub-directory) corresponding to that name from the root directory (if it exists) into the backup directory. If the context exits with an exception, all the files and directories affected by the transactional operations are restored, erasing new ones if needed. Example:

with Backup('mydir') as backup:
  p1 = backup('file1') # file1 is moved (if it exists) to the backup directory; p1 is the Path object for the new file1
  p2 = backup('dir2')
  p1.write_text('Hello world')
  ...
  raise Exception() # file1 and dir2 are restored, possibly erasing the new content in p1,p2
Parameters:

  • p (str | Path)

  • name (str)

XPOSE.utils.http_request(method, url, **ka)[source]

A thin layer around http.client.HTTPConnection.request(). Supports url in http, https schemes and works as a python context yielding a http.client.HTTPResponse object. The host specification in url can contain @ to provide basic authentication (eventually removed from url) in the form of a login-password pair separated by : (if the password is omitted, it is read from the terminal), e.g. https://joe@example.com/some/path?some=query.

With method GET, url can be a simple path to an existing file (ka must then be empty). The returned object supports only attributes status, reason, as well as method read(), as in http.client.HTTPResponse class.

Parameters:

  • method (str) – HTTP method name (case ignored)

  • url (str) – url to open

  • ka – same as in method http.client.HTTPConnection.request()
